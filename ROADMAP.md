# Product roadmap

## Stable candidate

- Recorded baseline/candidate JSONL comparison
- Strict JSON and caller-facing schema validation
- Deterministic built-in extraction evaluators
- Paired deployment and fully evaluated semantic analysis
- Local reports, release gates, replay, and verified archives

## Beta

- Command and Python variants
- Custom command and Python evaluators
- Cross-platform process containment and packaged installation

## Experimental

- OpenAI-compatible live execution
- Provider compatibility beyond retained local tests

## Required before public launch

- Clean packaged installation evidence on Linux, Intel and Apple Silicon macOS, and Windows
- Chromium, Firefox, WebKit/Safari, Edge, keyboard, and accessibility evidence
- External private-alpha installations and unaided workflows
- At least one real release decision with no misleading gate or privacy incident

These human and platform gates are evidence requirements, not tasks that can be marked complete by
adding code or documentation.
