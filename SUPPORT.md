# Support policy

Use GitHub Issues for reproducible product defects and focused feature proposals. Include the
StructTrace version, operating system, command, exit code, and a minimal sanitized fixture. Never
attach credentials, private prompts, customer records, or unredacted model output.

Security vulnerabilities belong in a private GitHub security advisory as described in
`SECURITY.md`. General implementation questions may use GitHub Discussions once enabled. There is
no paid support or response-time guarantee during the private alpha.

The recorded JSONL workflow receives correctness and security fixes first. Command, Python, and
custom evaluator integrations are Beta. OpenAI-compatible live execution is Experimental.
