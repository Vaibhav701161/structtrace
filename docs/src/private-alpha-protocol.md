The private alpha is limited to the recorded-JSONL workflow. Command and Python integrations are
Beta; OpenAI-compatible live execution is Experimental. A passing automated suite does not count
as external usability evidence.

installation path, whether help was required, workload type, dataset/evaluator authorship, commands
run, gate result, repeat-run result, misleading interpretation concerns, and privacy incidents.
