# Release-decision case-study template

Status: **PENDING real decision**.

Document the unchanged external contract, baseline/candidate implementations, evidence-unit policy,
dataset provenance, deterministic evaluators, primary outcome, preregistered gate, complete
denominators, paired transitions, interval, operational coverage, evidence diagnostics, replay result,
and the actual deployment decision.

Separate observed facts from interpretation. State every error, exclusion, repeated-trial group, and
limitation. Do not call a decision successful because it agrees with the maintainer’s preference.
