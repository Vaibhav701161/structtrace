# Privacy review checklist

Status: **PENDING per external workload**.

- [ ] Dataset owner approved local processing.
- [ ] Credentials exist only in named environment variables.
- [ ] Retention policy is selected before the run.
- [ ] Redaction pointers and custom patterns cover known sensitive fields.
- [ ] Case-level report stays on a trusted machine.
- [ ] Report is opened through the capability-protected loopback URL.
- [ ] Only the aggregate share derivative leaves the trusted environment.
- [ ] Export was manually inspected before sharing.
- [ ] Run storage and backups follow the organization’s deletion policy.
- [ ] Any privacy incident is recorded as a release blocker.
